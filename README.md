# ReCluttr

ReCluttr is a local-first desktop workspace for apps, web tabs, files, and everyday tools.

The goal is simple: make the desktop feel less scattered. ReCluttr brings browsing, app-like tools, local library views, downloads, settings, and installable ReCluttr apps into one calm tabbed workspace.

[recluttr.com](https://recluttr.com)

## What We Are Building

ReCluttr is Windows-first and built around a real desktop shell, not just a web page in a wrapper.

It combines:

- **Workspace tabs** for ReCluttr pages, apps, tools, and browser tabs.
- **Local-first storage** so the app remains useful without cloud services.
- **My Library** for focused views into common local folders.
- **App Library** for installing and managing ReCluttr apps.
- **Addons and SDK tooling** for extending what the workspace can do.
- **Built-in utilities** that live beside the rest of your work.
- **Premium cloud and business services** for sync, collaboration, shared storage, and hosted workflows.

ReCluttr should feel like one connected workspace instead of another pile of disconnected windows.

## Open Source Direction

This GitHub organization is for the parts of ReCluttr that are meant to be open and collaborative:

- ReCluttr apps
- Addons
- SDK examples
- Indexing and search modules
- Documentation
- Community tools
- Bug reports and feature discussions

The core desktop shell is kept controlled separately so the runtime, security model, update flow, and product direction stay consistent while ReCluttr grows.

## First App

**CalcPlus** is the first flagship ReCluttr app.

It is an advanced calculator for expressions, graphing, algebra, matrices, statistics, units, and related workflows. It also acts as a reference for how ReCluttr apps can live inside the workspace instead of becoming separate utility windows.

## Design Principles

- **Local first**: the desktop app should stand on its own.
- **Calm UI**: powerful tools should not feel noisy.
- **User control**: files, settings, and workflows should be understandable.
- **Composable tools**: apps, tabs, pages, and addons should feel like parts of one system.
- **Practical privacy**: cloud features should add convenience without replacing the local experience.

## Current Focus

ReCluttr is early and actively evolving. The current work is focused on:

- Polishing the Windows app.
- Improving browser tabs and workspace restore.
- Expanding the App Library and addon system.
- Preparing public SDK and app documentation.
- Building useful first-party apps.
- Making contribution paths clear before wider community development.

## How To Help

Helpful contributions include:

- Testing builds and reporting bugs.
- Suggesting apps, tools, and workflows that belong in ReCluttr.
- Improving documentation.
- Contributing to open apps and addons.
- Sharing UI, accessibility, and product feedback.

Good bug reports include what happened, what you expected, steps to reproduce it, your ReCluttr version, and your Windows version.

## Status

ReCluttr is not trying to replace every desktop app overnight. It is building toward a better workspace where apps, browser tabs, local files, utilities, and future services can feel like one coherent system.
